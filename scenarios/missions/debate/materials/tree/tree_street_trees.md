# 가로수 관리 현황

> 토론용으로 만든 가상의 지역 자료입니다.

## 가로수 상태 조사

| 상태 | 비율 |
|---|---|
| 건강 | 61% |
| 쇠약(가지 마름·병해) | 27% |
| 고사·제거 필요 | 12% |

- 해마다 약 900그루가 말라 죽어 다시 심는다. 다시 심는 비용은 그루당 약 50만 원이다.
- 고사 원인은 가뭄 때 물 부족(41%), 뿌리 공간 부족(33%), 과도한 가지치기(15%) 순이다.

## 관리 인력

- 관리 인력 1명이 가로수 약 6,000그루를 맡는다.
- F시는 주민이 가로수를 입양해 물 주기와 상태 신고를 맡는 제도를 운영했다. 입양된 나무의 고사율은 4%로, 입양되지 않은 나무(13%)보다 낮았다.
