# 도시 녹지율 통계

> 토론용으로 만든 가상의 지역 자료입니다.

## 동네별 녹지

| 구역 | 1인당 녹지(㎡) | 걸어서 10분 안에 공원이 있는 가구 |
|---|---|---|
| 구도심 | 3.1 | 41% |
| 신도시 | 11.8 | 88% |
| 산업단지 주변 | 2.4 | 29% |

- 권장 기준(1인당 9㎡)에 못 미치는 구역이 전체 면적의 46%다.
- 구도심은 빈 땅이 없어 새 공원을 만들기 어렵고, 옥상 면적은 넓다(구도심 건물 옥상 합계 약 38만㎡).

## 변화

- 지난 10년 동안 재개발로 녹지 약 52ha가 줄었다. 그중 31ha가 오래된 숲이었다.
