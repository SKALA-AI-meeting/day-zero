# 개발 설계 문서

실행 방법은 루트 `README.md`, 작업 진행 상태는 루트 `DEVELOPMENT.md`에서 확인한다.

- `common/architecture.md`: 서비스 구성과 데이터 흐름
- `common/contracts.md`: REST·WebSocket·MCP 인터페이스
- `common/data-model.md`: 저장 모델
- `common/scenario-model.md`: 페르소나·단계·카드 규칙
- `common/rubric.md`: 행동 기준 척도와 평가 출력
- `common/harness.md`: 에이전트 실행·복구·관측 설계
- `api/design.md`, `agent/design.md`, `mcp/design.md`, `worker-infra/design.md`: 서비스별 설계
- `frontend/design.md`, `frontend/design-system.md`: 화면과 디자인 시스템

기획서·과제 보고서·오케스트레이터 운영 문서·과거 캡처는 제출본에서 제외했다.
