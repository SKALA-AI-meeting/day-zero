# Day Zero

지원자가 AI 동료 3명과 채팅으로 토론하고 기획안을 제출하면, 그 과정의 협업 태도를 행동 근거로 살펴보는 채용 서비스입니다.

## 서비스

키워드 → 문제 상황 → 해결책을 함께 정하고, 지원자가 최종 기획안을 작성합니다. 60분 세션과 15분 데모를 지원하며 참고 자료와 AI 어시스턴트를 제공합니다.

세션 종료 후 AI가 공개된 행동 기준 척도로 근거 리포트를 만들고, 채용 담당자가 이를 참고해 최종 평가합니다. 안의 품질 대신 토론 태도를 관찰하며 합격·불합격·순위·총점은 생성하지 않습니다.

## 아키텍처

| 구성 | 역할 |
|---|---|
| **Web** · Next.js / React | 지원자 토론방, 기획안, 관리자·리포트 화면 |
| **API / Agent** · FastAPI / LangGraph | 인증, 세션 상태, WebSocket, 턴 매니저·페르소나 3명·어시스턴트 |
| **debate-mcp** | 토론 상태 조회, 발언, 의견·합의 처리 |
| **rag-mcp** · BGE-M3 / pgvector | 공개된 참고 자료 검색·조회 |
| **assessment-mcp** | 별도 토큰으로 보호된 관찰·평가 도구 |
| **Report Worker** · LangGraph | 큐 소비, 행동 근거 평가, 리포트 생성·확정 |
| **PostgreSQL / RabbitMQ** | 세션·기록·체크포인트 저장, 리포트 작업 큐·재시도 |

토론 요청은 API의 세션별 메일박스에서 순서대로 처리하고, 에이전트가 MCP 도구를 통해 자료와 상태에 접근합니다. AI 동료에게는 평가 도구 접근 권한을 주지 않습니다. 세션이 끝나면 큐를 통해 평가 워커가 실행됩니다.
